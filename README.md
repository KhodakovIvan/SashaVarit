# SashaVarit

Бот офисных обедов с [edatomsk.ru](https://www.edatomsk.ru/) («Саша варит», Томск).

Люди выбирают блюда в Telegram Mini App. Организатор смотрит сводку и подтверждает. Бот заполняет тот же офисный XLS, что скачивается с сайта, и отправляет его письмом на `mail@edatomsk.ru`. Корзину на сайте бот не трогает.

## Как это работает

Участники - подписчики канала. Кто не подписан, в личке и в Mini App получает отказ: «Бот работает только для подписчиков канала.» Организатор - любой администратор этого канала (создатель или admin). Отдельного списка id в конфиге нет, бот смотрит `getChatMember`. Сам бот тоже должен быть админом канала, иначе не сможет постить и проверять подписку.

День считается по `TIMEZONE` (по умолчанию Томск). В будни в `POST_HOUR:POST_MINUTE` бот сам публикует меню в канал и, если у канала есть связанный чат комментариев, дублирует туда. Кнопка «Заказать обед» открывает личку с ботом, не Mini App внутри канала: Telegram так надежнее. В личке кнопка «Открыть меню» (и кнопка «Меню» у поля ввода). Руками то же делает `/post`: публикует меню и открывает сбор на сегодня.

В Mini App меню текущего дня. Категории и цены - из XLS сайта (`old.edatomsk.ru/backend/toExcel`). Что сегодня сняли и что весовое - из JSON `srvItemsList.php` (`hide`, `weighty`, названия). Фото, состав, вес, КБЖУ - с HTML страницы дня. Поиск фильтрует по названию, составу и категории («ё» и «е» не различает). Карточка блюда открывается кнопкой i. Весовые с бейджем «вес», цена в заказе ориентировочная.

Один человек - один заказ на день. Пока сбор открыт, состав можно менять и снова жать «Сохранить». После сохранения бот пишет в личку позиции, сумму и КБЖУ (если на сайте есть данные; для весовых помечает, что ориентировочно). Заказы лежат в `data/orders.sqlite`, ключ `(день, telegram user id)`. Имена в консоль бот не пишет, они есть в сводке и в этой базе.

Сбор закрывается командой `/close` или по дедлайну, если `DEADLINE_ENABLED=1`. Тогда Mini App только смотреть: плюс недоступен. Минус у снятых блюд оставляют, чтобы человек мог убрать позицию. `/open` снова открывает сбор и снимает флаг «уже отправляли».

Перед `/summary` и `/send` меню снимается с сайта заново. Если в чьем-то заказе блюдо с `hide` или его уже нет в сегодняшнем XLS, письмо не уходит, сбор не закрывается. Организатору список: кто и какие названия пропали (имя берется из JSON сайта и запоминается в SQLite, даже если строки уже нет в XLS). В Mini App такие позиции в блоке «Нет на сайте».

`/send` показывает сводку и XLS, затем кнопки «Отправить письмо» / «Пока нет». Перед этим нужны адрес офиса в `.env` (`DELIVERY_ADDRESS`) и контактный телефон того администратора, кто жмёт отправку (`/phone` или кнопка с контактом Telegram). Если номера нет, бот не шлёт письмо и просит его сохранить. В письмо попадает адрес из настроек и телефон отправителя, не всех админов.

После подтверждения:

1. Еще раз сверка с сайтом.
2. Письмо на `ORDER_EMAIL_TO` с XLS во вложении: шапка (доставка, контакт), сводка, вложение. Если SMTP не задан, письмо не шлется (dry-run): лист и текст письма уходят организатору в личку, в канал XLS с пометкой, что это тест.
3. В канал тот же XLS с подписью «Обед заказан!»
4. Заказы за день стираются, сбор закрывается, день помечается как отправленный. Повторный `/send` в этот день не пройдет, пока не сделают `/open`.

XLS как на сайте: колонки людей, цена числом (иначе Excel не считает), последняя колонка «Итого» - формула `SUM(количества)×цена`, строка «Сумма, руб» - `цена×количество` по каждому и `SUM` по итоговой колонке. Весовые в названии со звездочкой.

Если дедлайн включен, в это время сбор закрывается, администраторам канала уходит сводка и кнопка отправки письма.

## Настройки

Все из файла `.env` в корне (скопировать из `.env.example`). В git он не попадает. Пустые значения значат «выключено» или значение по умолчанию из кода.

### Telegram и доступ

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `BOT_TOKEN` | пусто, без него не стартует | Токен BotFather |
| `CHANNEL_ID` | пусто | Канал вида `-100…`. По нему проверяется подписка и админы, туда посты и готовый XLS |
| `TELEGRAM_PROXY` | пусто, прямое соединение | SOCKS, если `api.telegram.org` недоступен, например `socks5://127.0.0.1:10808`. Hiddify / v2rayN должны быть запущены |

В BotFather у бота должен быть разрешен Mini App на текущий HTTPS-домен. Бот - администратор канала. Канал с комментариями: пост уйдет и в связанный чат.

`CHANNEL_ID` можно взять из ссылки или командой `/id` у себя, для канала удобнее форвард служебного сообщения или API. Формат обязательно `-100…`.

### Mini App и HTTP

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `WEBAPP_URL` | пусто | Свой постоянный HTTPS (свой туннель, ngrok, домен). Если пусто, при старте запускается cloudflared quick tunnel `*.trycloudflare.com` |
| `LISTEN_HOST` | `127.0.0.1` | На каком интерфейсе слушать Mini App |
| `LISTEN_PORT` | `8080` | Порт. Туннель пробрасывает его наружу |

Quick tunnel каждый запуск дает новый URL. Для постоянной работы лучше `WEBAPP_URL` на стабильный домен и тот же домен в BotFather. `cloudflared` должен быть в PATH, если `WEBAPP_URL` пустой.

### Почта

Письмо уходит только если заданы `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` (если `SMTP_FROM` пустой, подставляется `SMTP_USER`) и `ORDER_EMAIL_TO`. Иначе `/send` имитирует отправку: XLS собирается, в канал и организатору уходит, на кухню нет.

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `SMTP_HOST` | `smtp.yandex.ru` | SMTP-сервер |
| `SMTP_PORT` | `587` | Порт, соединение STARTTLS |
| `SMTP_USER` | пусто | Логин |
| `SMTP_PASSWORD` | пусто | Пароль приложения, не обычный пароль Яндекса |
| `SMTP_FROM` | как `SMTP_USER` | Поле From |
| `ORDER_EMAIL_TO` | `mail@edatomsk.ru` | Куда слать заказ |

### Доставка

Адрес офиса один на всех, в `.env`. Телефон у каждого администратора свой: бот запоминает его в SQLite (`admin_contacts`) по Telegram id. В письмо идет номер того, кто нажал «Отправить письмо».

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `DELIVERY_ADDRESS` | пусто, без него `/send` не отправит | Улица, дом, офис для кухни |
| `DELIVERY_COMMENT` | пусто | Домофон, этаж, как пройти. Строка под адресом в письме |

Админ один раз пишет `/phone` и жмёт «Отправить номер телефона» (Telegram отдаст контакт) или `/phone +79131234567`. Номер можно сменить той же командой. Чужой контакт бот не принимает.

### Расписание

Время везде в `TIMEZONE`. Задачи только пн-пт.

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `TIMEZONE` | `Asia/Tomsk` | «Сегодня», дедлайн, крон |
| `POST_HOUR` / `POST_MINUTE` | `8` / `0` | Автопост меню в канал |
| `DEADLINE_HOUR` / `DEADLINE_MINUTE` | `9` / `15` | Во сколько закрыть сбор, если дедлайн включен |
| `DEADLINE_ENABLED` | `0` (выключен) | `1` / `true` / `yes` / `on` - в это время закрыть сбор и написать админам сводку. `0` - дедлайн не срабатывает, закрывать вручную `/close` или после `/send` |

Пример рабочего дня: пост в 08:00, сбор до 09:15, потом `/send`. Для тестов удобно `DEADLINE_ENABLED=0`.

Данные: каталог `data/` (SQLite заказов, запомненные названия блюд, телефоны админов). В git не коммитится.

## Запуск

Нужны Python 3.11+ и [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation/), если нет своего `WEBAPP_URL`.

```powershell
python -m venv .venv
.\.venv\Scripts\pip.exe install -r requirements.txt
copy .env.example .env
```

Заполните хотя бы `BOT_TOKEN`, `CHANNEL_ID` и `DELIVERY_ADDRESS`.

```powershell
.\.venv\Scripts\python.exe run.py
```

После смены Python-кода процесс перезапустить. Файлы в `webapp/` отдаются с диска, достаточно заново открыть Mini App.

## Команды

В личке, для подписчика канала:

| Команда | Что делает |
|---|---|
| `/start` | Кнопки меню. Админам канала еще список их команд |
| `/menu` | Снова открыть Mini App |
| `/id` | Telegram id |

Только администраторам канала:

| Команда | Что делает |
|---|---|
| `/post` | Пост меню в канал, сбор открыт |
| `/summary` | Сводка и XLS, без письма. Если что-то сняли с сайта - список |
| `/close` | Закрыть сбор |
| `/open` | Открыть сбор и разрешить `/send` снова |
| `/send` | Сверка с сайтом, сводка, подтверждение, письмо и XLS в канал |
| `/phone` | Сохранить свой номер для письма. Без него `/send` не отправит |
